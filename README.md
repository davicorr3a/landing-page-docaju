# DocAju

Página de divulgação do DocAju, ferramenta que transforma as ações do usuário no navegador em manuais com passos e capturas de tela, prontos para revisar e exportar em PDF, slides ou Markdown. O projeto foi desenvolvido por alunos do Departamento de Computação da Universidade Federal de Sergipe.

A página é estática, feita com HTML, CSS e JavaScript, e segue a identidade visual do DocAju e o Manual de Marca da UFS. Para visualizar, basta abrir o arquivo `index.html` no navegador ou publicar a pasta em um serviço de hospedagem estática, como Vercel ou GitHub Pages.
